## 1. Project Brief

### 1.1 Objective

Build a production-ready, regulation-compliant e-commerce clinic and pharmaceutical web application for the Kenyan market. The platform must support:

- Telehealth consultations (video, chat, voice)
- E-prescriptions with FHIR R4 compliance
- Pharmacy inventory and dispensing workflows
- OTC product and medical device e-commerce
- M-PESA, Airtel Money, card, and SHA payments
- Boda-boda–centric last-mile delivery with real-time tracking
- USSD and SMS fallback for feature phones
- Full audit trails for PPB and ODPC compliance

### 1.2 Core Design Principles

1. **Data localisation first** — PHI never leaves Kenyan infrastructure
2. **Mobile-first, data-light** — optimized for 3G/4G and limited data budgets
3. **Payment-native** — M-PESA is the default, not an add-on
4. **Address-free logistics** — phone number + landmark is the primary delivery identifier
5. **Database-level security** — Row Level Security enforces access, not application code
6. **Immutable audit** — every PHI access is logged and retained for 6 years

### 1.3 User Roles

| Role | Description | Primary Surface |
|---|---|---|
| **Patient** | End consumer of clinical and pharmacy services | Web + Mobile |
| **Provider** | Licensed clinician conducting consultations | Web + Mobile |
| **Pharmacist** | Licensed dispenser managing inventory and orders | Web |
| **Admin** | Platform operator managing compliance and analytics | Web |
| **Rider** | Boda-boda courier handling last-mile delivery | Mobile (lightweight) |

## 2. Tech Stack

### 2.1 Mandatory Stack

| Layer | Technology | Notes |
|---|---|---|
| **Web Frontend** | Next.js 14+ (App Router), TypeScript, Tailwind CSS, ShadCN/UI | SSR/SSG for performance |
| **Mobile Frontend** | Flutter (iOS + Android) | USSD/SMS fallback required |
| **Primary Database** | Self-hosted Supabase (PostgreSQL 15+) | Kenyan VPS — data residency |
| **Edge Compute** | Cloudflare Workers | API gateway, M-PESA, FHIR proxy |
| **Edge Functions** | Supabase Edge Functions (Deno) | Webhooks, transformations |
| **Object Storage (non-PHI)** | Cloudflare R2 | Zero egress fees |
| **Object Storage (PHI)** | Self-hosted MinIO | Kenyan VPS |
| **Authentication** | Supabase Auth | MFA (TOTP + SMS) |
| **Real-time** | Supabase Realtime | Chat, tracking, notifications |
| **Queue / Async** | Cloudflare Queues | Order processing, dispatch |
| **AI / Clinical Support** | Cloudflare Workers AI (Llama 3.1 8B) | Triage, symptom analysis |
| **SMS / OTP** | Africa's Talking API | More reliable than push in rural areas |
| **Payments** | M-PESA Daraja 3.0 via `pesafy` SDK | STK Push, C2B, B2C |
| **Audit Logging** | pgAudit + Supabase audit logs + Cloudflare Logpush | 6-year retention |
| **IaC** | Terraform | Reproducible environments |
| **CI/CD** | GitHub Actions + Docker | Blue-green deployments |

### 2.2 Explicitly Rejected Technologies

| Technology | Reason for Rejection |
|---|---|
| **Cloudflare D1** | 10 GB limit, single-threaded — unsuitable for clinical workloads |
| **Cloudflare R2 for PHI** | No African storage region — violates DPA Section 50 |
| **Shopify / standard SaaS e-commerce** | Cannot sign BAAs for PHI workloads |
| **Public LLM APIs (OpenAI, Anthropic)** | PHI cannot be sent to non-BAA endpoints |
| **Supabase Cloud (non-self-hosted)** | Data residency non-compliance for PHI |

## 3. Regulatory & Compliance Requirements

These are **non-negotiable**. The build must satisfy all of them before launch.

### 3.1 Kenya Data Protection Act 2019 (ODPC)

- **Section 50 — Data Localisation:** Personal data processed for the provision of primary or secondary health care must be domiciled in Kenya. This mandates self-hosted Supabase and MinIO on Kenyan VPS infrastructure.
- **ODPC Registration:** Register as data controller/processor. Health data controllers must additionally notify the **Digital Health Agency (DHA) within 7 days**.
- **DPIA:** Conduct and document a Data Protection Impact Assessment covering all Cloudflare–Supabase data flows.
- **Consent Management:** Granular opt-in for PHI processing, with timestamped records. Data subject rights (access, deletion, portability) must be implemented.

### 3.2 Pharmacy and Poisons Board (PPB)

- **Digital Pharmacy Licence:** Required under the *Guidelines for Internet Pharmacy Services in Kenya (rev. April 2023)* and *Pharmacy and Poisons (Amendment) Rules, 2022*.
- **Display Requirements:** PPB licence number, pharmacist registration number, and KMHFR facility ID must be prominently displayed, with a hyperlink to the PPB website.
- **Audit Trail (Guideline 7.1.5):** Immutable audit trail from medicine request to delivery.
- **Transport Rules:** All delivery partners must hold a *Pharmacy and Poisons (Transportation of Pharmaceuticals) Rules, 2022* licence. Patient confidentiality must be safeguarded in transit.

### 3.3 Digital Health Act 2023

- **Platform Certification:** The platform must be certified by the Digital Health Agency under the national Certification Framework.
- **Telemedicine Registry:** All providers must be qualified, registered, and licensed in Kenya, and listed on the national telemedicine health provider registry.
- **FHIR Interoperability:** HL7 FHIR R4 and LOINC coding are formal requirements for national-level health systems. Integration with the Health Information Exchange (HIE) via the Interoperability Services Layer is required.

### 3.4 Social Health Authority (SHA)

- **Empanelment:** Only licensed and accredited facilities can be empanelled under SHA. Complete empanelment for claims processing and reimbursement.
- **Afya Yangu Integration:** Support e-prescription viewing and clinical decision support via the SHA Afya Yangu portal.
- **AI Clinical Support:** Support SHA's AI tooling that evaluates whether a prescribed medicine is harmful to the patient.

### 3.5 Compliance Matrix

| Requirement | Owner | Evidence |
|---|---|---|
| ODPC registration certificate | Admin | Certificate of Data Handler |
| DHA notification (within 7 days) | Admin | Acknowledgement receipt |
| DPIA document | Admin | Signed DPIA report |
| PPB digital pharmacy licence | Pharmacist | Licence number displayed |
| KMHFR facility registration | Pharmacist | Facility ID |
| Platform certification (DHA) | Admin | Certification certificate |
| Pharmaceutical transport licences | Logistics | Partner licence copies |
| SHA empanelment | Admin | Empanelment confirmation |
| Audit log retention (6 years) | Engineering | `AUDIT_LOG_RETENTION_DAYS=2190` |

### 4.2 Data Classification & Routing

| Data Type | Classification | Storage Location | Rationale |
|---|---|---|---|
| Patient records, prescriptions, diagnoses | **PHI** | Kenyan VPS (Supabase/MinIO) | DPA Section 50 |
| Prescription images, lab results | **PHI** | Kenyan VPS (MinIO) | DPA Section 50 |
| Product catalog, UI assets, blog | Non-PHI | Cloudflare R2 | Cost, performance |
| Audit logs | Sensitive | Kenyan VPS (PostgreSQL) | PPB 6-year retention |
| Session tokens, cache | Ephemeral | Cloudflare KV / Redis | Performance |
| Analytics (anonymised) | Aggregated | Cloudflare R2 | Non-PHI after de-identification |

### 4.3 Payment Abstraction Layer

All payment providers are normalised into a single internal transaction model so new PSPs can be added without rewriting checkout logic.

```
Checkout Request
      │
      ▼
┌─────────────────────┐
│ Payment Orchestrator│  (Cloudflare Worker)
│  - Method routing   │
│  - Idempotency      │
│  - State machine    │
└──────────┬──────────┘
           │
   ┌───────┼───────┬──────────┬─────────┐
   ▼       ▼       ▼          ▼         ▼
 M-PESA  Airtel  Pesalink   Card      SHA
 Daraja  Money   (Paystack) (PSP)     (Claims)
   │       │       │          │         │
   └───────┴───────┴──────────┴─────────┘
                    │
                    ▼
           Unified Transaction
           { id, method, amount_kes,
             status, external_ref,
             callback_payload, audit_id }
```

### 4.4 Delivery Architecture (Address-Free)

Kenya has no universal physical addressing system. The platform uses:

1. **Phone number as primary identifier** — the recipient's mobile number, not a street address
2. **Landmark-based descriptor** — free-text field, e.g. "Near Equity Bank, Kasarani"
3. **GPS pin-drop** — optional, urban areas only
4. **Pick-up point network** — for non-urgent refills in high-demand towns
5. **Community Health Promoters (CHPs)** — assisted ordering and collection for elderly/low-literacy patients

**Delivery Workflow:**

```
Patient places order
      │
      ▼
Select delivery method
  ├─ Boda-Boda (same-day)  → dispatch API → rider app
  ├─ Pick-up Point         → SMS code to patient
  └─ Clinic Collection     → appointment slot
      │
      ▼
Rider confirms pickup from licensed pharmacy
      │
      ▼
En route (live GPS tracking to patient)
      │
      ▼
Delivery → photo + OTP proof
      │
      ▼
Chain-of-custody logged (timestamps, rider ID, GPS trail)
```

## 6. Database Schema

All tables live in the `public` schema of the self-hosted Supabase PostgreSQL instance. **RLS is enabled on every table containing patient-adjacent data.**

### 6.1 Extensions

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";
CREATE EXTENSION IF NOT EXISTS "pg_audit";
CREATE EXTENSION IF NOT EXISTS "pg_trgm";  -- fuzzy drug name search
```

### 6.2 Core Tables

```sql
-- ============================================================
-- PROFILES (extends auth.users)
-- ============================================================
CREATE TABLE public.profiles (
  id UUID REFERENCES auth.users ON DELETE CASCADE PRIMARY KEY,
  role TEXT NOT NULL CHECK (role IN ('patient','provider','pharmacist','admin','rider')),
  full_name TEXT NOT NULL,
  phone TEXT UNIQUE NOT NULL,          -- E.164: +2547XXXXXXXX
  email TEXT,
  national_id TEXT UNIQUE,             -- Kenyan National ID (hashed at rest in prod)
  odpc_consent_given BOOLEAN DEFAULT FALSE,
  odpc_consent_timestamp TIMESTAMPTZ,
  mfa_enabled BOOLEAN DEFAULT FALSE,
  preferred_language TEXT DEFAULT 'en' CHECK (preferred_language IN ('en','sw')),
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- PHARMACIES (licensed entities)
-- ============================================================
CREATE TABLE public.pharmacies (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL,
  ppb_licence_number TEXT UNIQUE NOT NULL,
  ppb_licence_expiry DATE NOT NULL,
  kmhfr_facility_id TEXT UNIQUE NOT NULL,
  pharmacist_registration_number TEXT NOT NULL,
  physical_address TEXT NOT NULL,
  county TEXT NOT NULL,                -- One of Kenya's 47 counties
  gps_lat DECIMAL(10,7),
  gps_lng DECIMAL(10,7),
  delivery_radius_km INTEGER DEFAULT 15,
  is_active BOOLEAN DEFAULT TRUE,
  is_sha_empanelled BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- PROVIDERS (clinicians)
-- ============================================================
CREATE TABLE public.providers (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  profile_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE,
  licence_number TEXT UNIQUE NOT NULL,       -- Kenya Medical Practitioners licence
  specialisation TEXT NOT NULL,
  telemedicine_registry_id TEXT UNIQUE,      -- National telemedicine registry
  is_available BOOLEAN DEFAULT TRUE,
  consultation_fee_kes DECIMAL(10,2),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- PATIENTS
-- ============================================================
CREATE TABLE public.patients (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  profile_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE UNIQUE,
  date_of_birth DATE NOT NULL,
  gender TEXT CHECK (gender IN ('male','female','other','prefer_not_to_say')),
  sha_member_number TEXT UNIQUE,
  blood_type TEXT,
  allergies TEXT[],
  chronic_conditions TEXT[],
  primary_county TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- PRODUCTS (pharmacy inventory)
-- ============================================================
CREATE TABLE public.products (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  pharmacy_id UUID REFERENCES public.pharmacies(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  generic_name TEXT,
  swahili_name TEXT,                   -- For bilingual search
  category TEXT NOT NULL CHECK (category IN ('prescription','otc','device','supplement')),
  price_kes DECIMAL(10,2) NOT NULL CHECK (price_kes >= 0),
  stock_quantity INTEGER DEFAULT 0 CHECK (stock_quantity >= 0),
  reorder_threshold INTEGER DEFAULT 10,
  batch_number TEXT,
  expiry_date DATE,
  requires_prescription BOOLEAN DEFAULT FALSE,
  ppb_registration_number TEXT,
  image_url TEXT,
  search_vector TSVECTOR,              -- Generated for full-text search
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_products_search ON public.products USING GIN(search_vector);
CREATE INDEX idx_products_expiry ON public.products(expiry_date) WHERE expiry_date IS NOT NULL;

-- Auto-populate search vector
CREATE OR REPLACE FUNCTION update_product_search() RETURNS TRIGGER AS $$
BEGIN
  NEW.search_vector :=
    setweight(to_tsvector('english', COALESCE(NEW.name,'')), 'A') ||
    setweight(to_tsvector('english', COALESCE(NEW.generic_name,'')), 'A') ||
    setweight(to_tsvector('simple',  COALESCE(NEW.swahili_name,'')), 'A');
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_product_search BEFORE INSERT OR UPDATE ON public.products
  FOR EACH ROW EXECUTE FUNCTION update_product_search();

-- ============================================================
-- PRESCRIPTIONS
-- ============================================================
CREATE TABLE public.prescriptions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  patient_id UUID REFERENCES public.patients(id) ON DELETE CASCADE,
  provider_id UUID REFERENCES public.providers(id),
  pharmacy_id UUID REFERENCES public.pharmacies(id),
  medication_name TEXT NOT NULL,
  generic_name TEXT,
  dosage TEXT NOT NULL,
  frequency TEXT NOT NULL,
  duration_days INTEGER,
  refills_remaining INTEGER DEFAULT 0 CHECK (refills_remaining >= 0),
  status TEXT DEFAULT 'pending'
    CHECK (status IN ('pending','approved','dispensed','cancelled','expired')),
  fhir_resource JSONB,                 -- Full FHIR MedicationRequest
  clinical_notes TEXT,
  sha_claim_status TEXT DEFAULT 'not_submitted'
    CHECK (sha_claim_status IN ('not_submitted','submitted','approved','rejected')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_prescriptions_patient ON public.prescriptions(patient_id);
CREATE INDEX idx_prescriptions_status ON public.prescriptions(status);

-- ============================================================
-- CONSULTATIONS (Telehealth sessions)
-- ============================================================
CREATE TABLE public.consultations (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  patient_id UUID REFERENCES public.patients(id) ON DELETE CASCADE,
  provider_id UUID REFERENCES public.providers(id),
  scheduled_at TIMESTAMPTZ NOT NULL,
  started_at TIMESTAMPTZ,
  ended_at TIMESTAMPTZ,
  status TEXT DEFAULT 'scheduled'
    CHECK (status IN ('scheduled','in_progress','completed','cancelled','no_show')),
  consultation_type TEXT CHECK (consultation_type IN ('video','audio','chat')),
  fee_kes DECIMAL(10,2),
  payment_status TEXT DEFAULT 'pending'
    CHECK (payment_status IN ('pending','paid','waived','failed')),
  soap_notes JSONB,                    -- { subjective, objective, assessment, plan }
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- ORDERS
-- ============================================================
CREATE TABLE public.orders (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  order_number TEXT UNIQUE NOT NULL,   -- Human-readable: AFY-2026-000123
  patient_id UUID REFERENCES public.patients(id),
  pharmacy_id UUID REFERENCES public.pharmacies(id),
  prescription_id UUID REFERENCES public.prescriptions(id),
  subtotal_kes DECIMAL(10,2) NOT NULL,
  delivery_fee_kes DECIMAL(10,2) DEFAULT 0,
  total_kes DECIMAL(10,2) NOT NULL,
  payment_status TEXT DEFAULT 'pending'
    CHECK (payment_status IN ('pending','paid','failed','refunded','partially_refunded')),
  payment_method TEXT CHECK (payment_method IN ('mpesa','airtel_money','pesalink','card','sha','cash')),
  payment_reference TEXT,              -- Internal unified transaction ID
  mpesa_checkout_request_id TEXT,
  mpesa_receipt_number TEXT,
  delivery_status TEXT DEFAULT 'pending'
    CHECK (delivery_status IN ('pending','confirmed','dispatched','in_transit','delivered','failed','cancelled')),
  delivery_method TEXT CHECK (delivery_method IN ('boda','pickup_point','clinic_collection')),
  delivery_address JSONB NOT NULL,
    -- { phone, landmark, county, gps_lat, gps_lng, notes }
  rider_id UUID REFERENCES public.profiles(id),
  proof_of_delivery JSONB,             -- { photo_url, otp_verified, gps_at_delivery, timestamp }
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_orders_patient ON public.orders(patient_id);
CREATE INDEX idx_orders_status ON public.orders(delivery_status);
CREATE INDEX idx_orders_number ON public.orders(order_number);

-- ============================================================
-- ORDER ITEMS
-- ============================================================
CREATE TABLE public.order_items (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  order_id UUID REFERENCES public.orders(id) ON DELETE CASCADE,
  product_id UUID REFERENCES public.products(id),
  quantity INTEGER NOT NULL CHECK (quantity > 0),
  unit_price_kes DECIMAL(10,2) NOT NULL,
  line_total_kes DECIMAL(10,2) NOT NULL
);

-- ============================================================
-- PAYMENT TRANSACTIONS (unified abstraction)
-- ============================================================
CREATE TABLE public.payment_transactions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  order_id UUID REFERENCES public.orders(id) ON DELETE CASCADE,
  provider TEXT NOT NULL CHECK (provider IN ('mpesa','airtel_money','pesalink','card','sha')),
  provider_reference TEXT,             -- e.g. CheckoutRequestID
  amount_kes DECIMAL(10,2) NOT NULL,
  status TEXT DEFAULT 'initiated'
    CHECK (status IN ('initiated','pending','succeeded','failed','reversed')),
  request_payload JSONB,
  callback_payload JSONB,
  idempotency_key TEXT UNIQUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- RIDERS
-- ============================================================
CREATE TABLE public.riders (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  profile_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE UNIQUE,
  plate_number TEXT NOT NULL,
  transport_licence_number TEXT NOT NULL,   -- Pharmacy & Poisons Transport Rules 2022
  transport_licence_expiry DATE NOT NULL,
  county TEXT NOT NULL,
  is_available BOOLEAN DEFAULT FALSE,
  current_lat DECIMAL(10,7),
  current_lng DECIMAL(10,7),
  last_ping_at TIMESTAMPTZ,

  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ============================================================
-- AUDIT LOG (immutable, append-only)
-- ============================================================
CREATE TABLE public.audit_log (

  actor_id UUID REFERENCES public.profiles(id),
  actor_role TEXT,
  action TEXT NOT NULL,                -- e.g. 'READ', 'CREATE', 'UPDATE', 'DISPENSE', 'EXPORT'
  resource_type TEXT NOT NULL,         -- e.g. 'prescription', 'patient', 'order'
  resource_id UUID,
```

```sql
-- Generic audit trigger function
CREATE OR REPLACE FUNCTION audit_trigger_func() RETURNS TRIGGER AS $$
DECLARE
  v_actor UUID;
  v_role TEXT;
BEGIN
  v_actor := auth.uid();
  SELECT role INTO v_role FROM public.profiles WHERE id = v_actor;

  INSERT INTO public.audit_log (
    actor_id, actor_role, action, resource_type, resource_id,
    phi_accessed, ip_address, metadata
  ) VALUES (
    v_actor,
    v_role,
    TG_OP,
    TG_TABLE_NAME,
    COALESCE(NEW.id, OLD.id),
    TG_TABLE_NAME IN ('patients','prescriptions','consultations','orders'),
    current_setting('request.headers', true)::json->>'x-forwarded-for',
    jsonb_build_object('old', to_jsonb(OLD), 'new', to_jsonb(NEW))
  );

  RETURN COALESCE(NEW, OLD);
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

### 8.1 Worker: M-PESA Payment Gateway

**File:** `workers/mpesa/src/index.ts`

```typescript
import { Mpesa } from 'pesafy';

export interface Env {
  MPESA_CONSUMER_KEY: string;
  MPESA_CONSUMER_SECRET: string;
  MPESA_PASSKEY: string;
  MPESA_SHORTCODE: string;
  MPESA_ENVIRONMENT: 'sandbox' | 'production';
  SUPABASE_URL: string;
  SUPABASE_SERVICE_KEY: string;
  CALLBACK_BASE_URL: string;
}

interface StkPushRequest {
  phone: string;       // E.164 +254...
  amount: number;      // KES
  orderId: string;
  orderNumber: string;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);
    const cors = {
      'Access-Control-Allow-Origin': 'https://afyacommerce.co.ke',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization',
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: cors });
    }

    // ---- Initiate STK Push ----
    if (url.pathname === '/api/mpesa/stk-push' && request.method === 'POST') {
      const body: StkPushRequest = await request.json();

      // Validate Kenyan phone number
      if (!/^\+254[17]\d{8}$/.test(body.phone)) {
        return Response.json(
          { error: 'Invalid Kenyan phone number' },
          { status: 400, headers: cors }
        );
      }

      const mpesa = new Mpesa({
        consumerKey: env.MPESA_CONSUMER_KEY,
        consumerSecret: env.MPESA_CONSUMER_SECRET,
        environment: env.MPESA_ENVIRONMENT,
        lipaNaMpesaShortCode: env.MPESA_SHORTCODE,
        lipaNaMpesaPassKey: env.MPESA_PASSKEY,
      });

      const response = await mpesa.stkPush({
        amount: Math.round(body.amount),
        phoneNumber: body.phone,
        callbackUrl: `${env.CALLBACK_BASE_URL}/api/mpesa/callback`,
        accountReference: body.orderNumber,
        transactionDesc: `AfyaCommerce ${body.orderNumber}`,
      });

      // Persist transaction state
      await fetch(`${env.SUPABASE_URL}/rest/v1/payment_transactions`, {
        method: 'POST',
        headers: {
          apikey: env.SUPABASE_SERVICE_KEY,
          Authorization: `Bearer ${env.SUPABASE_SERVICE_KEY}`,
          'Content-Type': 'application/json',
          Prefer: 'return=representation',
        },
        body: JSON.stringify({
          order_id: body.orderId,
          provider: 'mpesa',
          provider_reference: response.CheckoutRequestID,
          amount_kes: body.amount,
          status: 'pending',
          idempotency_key: `${body.orderId}-${response.CheckoutRequestID}`,
          request_payload: response,
        }),
      });

      return Response.json(response, { headers: cors });
    }

    // ---- M-PESA Callback ----
    if (url.pathname === '/api/mpesa/callback' && request.method === 'POST') {
      const callback = await request.json() as any;
      const cb = callback?.Body?.stkCallback;
      if (!cb) return new Response('Bad Request', { status: 400 });

      const { CheckoutRequestID, ResultCode, MpesaReceiptNumber, ResultDesc } = cb;

      const success = ResultCode === 0;

      // Update payment transaction
      await fetch(
        `${env.SUPABASE_URL}/rest/v1/payment_transactions?provider_reference=eq.${CheckoutRequestID}`,
        {
          method: 'PATCH',
          headers: {
            apikey: env.SUPABASE_SERVICE_KEY,
            Authorization: `Bearer ${env.SUPABASE_SERVICE_KEY}`,
            'Content-Type': 'application/json',
          },
          body: JSON.stringify({
            status: success ? 'succeeded' : 'failed',
            callback_payload: callback,
            updated_at: new Date().toISOString(),
          }),
        }
      );

      // Update order
      if (success) {
        await fetch(
          `${env.SUPABASE_URL}/rest/v1/orders?mpesa_checkout_request_id=eq.${CheckoutRequestID}`,
          {
            method: 'PATCH',
            headers: {
              apikey: env.SUPABASE_SERVICE_KEY,
              Authorization: `Bearer ${env.SUPABASE_SERVICE_KEY}`,
              'Content-Type': 'application/json',
            },
            body: JSON.stringify({
              payment_status: 'paid',
              mpesa_receipt_number: MpesaReceiptNumber,
              updated_at: new Date().toISOString(),
            }),
          }
        );
      }

      // M-PESA expects a plain 200
      return new Response('OK', { status: 200 });
    }

    // ---- Payment Status Poll ----
    if (url.pathname.startsWith('/api/mpesa/status/')) {
      const ref = url.pathname.split('/').pop();
      const res = await fetch(
        `${env.SUPABASE_URL}/rest/v1/payment_transactions?provider_reference=eq.${ref}&select=status`,
        {
          headers: {
            apikey: env.SUPABASE_SERVICE_KEY,
            Authorization: `Bearer ${env.SUPABASE_SERVICE_KEY}`,
          },
        }
      );
      const data = await res.json();
      return Response.json(data[0] ?? { status: 'unknown' }, { headers: cors });
    }

    return new Response('Not Found', { status: 404, headers: cors });
  },
};
```

### 8.2 Worker: FHIR / HIE Proxy

```typescript
export interface Env {
  HIE_BASE_URL: string;
  HIE_CLIENT_ID: string;
  HIE_CLIENT_SECRET: string;
  HIE_TOKEN_CACHE: KVNamespace;
}

async function getHieToken(env: Env): Promise<string> {
  const cached = await env.HIE_TOKEN_CACHE.get('hie_token');
  if (cached) return cached;

  const res = await fetch(`${env.HIE_BASE_URL}/auth/token`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      client_id: env.HIE_CLIENT_ID,
      client_secret: env.HIE_CLIENT_SECRET,
      grant_type: 'client_credentials',
    }),
  });
  const data = await res.json() as { access_token: string; expires_in: number };
  await env.HIE_TOKEN_CACHE.put('hie_token', data.access_token, {
    expirationTtl: data.expires_in - 60,
  });
  return data.access_token;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const url = new URL(request.url);

    if (!url.pathname.startsWith('/fhir/')) {
      return new Response('Not Found', { status: 404 });
    }

    const token = await getHieToken(env);
    const hieUrl = `${env.HIE_BASE_URL}${url.pathname.replace('/fhir', '')}${url.search}`;

    const hieResponse = await fetch(hieUrl, {
      method: request.method,
      headers: {
        Authorization: `Bearer ${token}`,
        'Content-Type': 'application/fhir+json',
        Accept: 'application/fhir+json',
      },
      body: ['GET', 'HEAD'].includes(request.method) ? undefined : request.body,
    });

    return new Response(hieResponse.body, {
      status: hieResponse.status,
      headers: {
        'Content-Type': 'application/fhir+json',
        'Access-Control-Allow-Origin': 'https://afyacommerce.co.ke',
      },
    });
  },
};
```

```typescript
import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

serve(async (req) => {
  const { prescriptionId } = await req.json();

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  const { data: rx, error } = await supabase
    .from('prescriptions')
    .select(`
      *,
      patients ( id, profile_id, sha_member_number, allergies,
                 profiles ( full_name, phone ) ),
      providers ( licence_number, specialisation,
                  profiles ( full_name ) )
    `)
    .eq('id', prescriptionId)
    .single();

  if (error || !rx) {
    return new Response(JSON.stringify({ error: 'Prescription not found' }), { status: 404 });
  }

  const fhirResource = {
    resourceType: 'MedicationRequest',
    id: rx.id,
    meta: {
      lastUpdated: rx.updated_at,
      profile: ['http://hl7.org/fhir/StructureDefinition/MedicationRequest'],
    },
    status: rx.status === 'dispensed' ? 'completed'
          : rx.status === 'approved'  ? 'active'
          : rx.status === 'cancelled' ? 'cancelled'
          : 'draft',
    intent: 'order',
    medicationCodeableConcept: {
      text: rx.medication_name,
      coding: rx.generic_name
        ? [{ system: 'http://snomed.info/sct', display: rx.generic_name }]
        : undefined,
    },
    subject: {
      reference: `Patient/${rx.patient_id}`,
      display: rx.patients?.profiles?.full_name,
    },
    authoredOn: rx.created_at,
    requester: {
      reference: `Practitioner/${rx.provider_id}`,
      display: rx.providers?.profiles?.full_name,
    },
    dosageInstruction: [{
      text: `${rx.dosage} ${rx.frequency}`,
      timing: { repeat: { duration: rx.duration_days, durationUnit: 'd' } },
    }],
    dispenseRequest: {
      numberOfRepeatsAllowed: rx.refills_remaining,
      validityPeriod: { end: new Date(Date.now() + 90 * 864e5).toISOString() },
    },
    note: rx.clinical_notes ? [{ text: rx.clinical_notes }] : undefined,
  };

  await supabase
    .from('prescriptions')
    .update({ fhir_resource: fhirResource })
    .eq('id', prescriptionId);

  return new Response(JSON.stringify(fhirResource), {
    headers: { 'Content-Type': 'application/fhir+json' },
  });
});
```

```typescript
import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

serve(async (req) => {
  const { orderId } = await req.json();

  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  const { data: order } = await supabase
    .from('orders')
    .select('*, pharmacies(gps_lat, gps_lng, county)')
    .eq('id', orderId)
    .single();

  if (!order) return new Response('Order not found', { status: 404 });

  // Find nearest available rider in same county
  const { data: riders } = await supabase
    .from('riders')
    .select('*')
    .eq('county', order.pharmacies.county)
    .eq('is_available', true)
    .order('last_ping_at', { ascending: false })
    .limit(5);

  if (!riders?.length) {
    await supabase.from('orders')
      .update({ delivery_status: 'pending' })
      .eq('id', orderId);
    return new Response(JSON.stringify({ error: 'No riders available' }), { status: 503 });
  }

  // Assign first rider (production: use geospatial nearest-neighbour)
  const rider = riders[0];

  await supabase.from('orders').update({
    rider_id: rider.profile_id,
    delivery_status: 'dispatched',
  }).eq('id', orderId);

  await supabase.from('riders')
    .update({ is_available: false })
    .eq('id', rider.id);

  return new Response(JSON.stringify({
    rider_id: rider.profile_id,
    rider_phone: rider.plate_number,
    pickup: { lat: order.pharmacies.gps_lat, lng: order.pharmacies.gps_lng },
    dropoff: order.delivery_address,
  }), { headers: { 'Content-Type': 'application/json' } });
```

### 10.3 Key Component: M-PESA Checkout

```tsx
// components/checkout/MpesaCheckout.tsx
'use client';

import { useState, useEffect, useRef } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';

interface Props {
  orderId: string;
  orderNumber: string;
  amount: number;
  onSuccess: (receipt: string) => void;
}

type Status = 'idle' | 'pending' | 'success' | 'failed';

export function MpesaCheckout({ orderId, orderNumber, amount, onSuccess }: Props) {
  const [phone, setPhone] = useState('');
  const [loading, setLoading] = useState(false);
  const [status, setStatus] = useState<Status>('idle');
  const pollRef = useRef<number | null>(null);

  useEffect(() => () => { if (pollRef.current) clearInterval(pollRef.current); }, []);

  const handlePayment = async () => {
    setLoading(true);
    setStatus('pending');

    try {
      const normalized = phone.replace(/^0/, '+254').replace(/\s/g, '');
      const res = await fetch('/api/mpesa/stk-push', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ phone: normalized, amount, orderId, orderNumber }),
      });

      if (!res.ok) throw new Error('STK push failed');
      const { CheckoutRequestID } = await res.json();

      let elapsed = 0;
      pollRef.current = window.setInterval(async () => {
        elapsed += 3000;
        const s = await fetch(`/api/mpesa/status/${CheckoutRequestID}`).then(r => r.json());

        if (s.status === 'succeeded') {
          clearInterval(pollRef.current!);
          setStatus('success');
          onSuccess(s.mpesa_receipt ?? '');
        } else if (s.status === 'failed') {
          clearInterval(pollRef.current!);
          setStatus('failed');
        } else if (elapsed >= 90000) {
          clearInterval(pollRef.current!);
          setStatus('failed');
        }
      }, 3000);
    } catch {
      setStatus('failed');
    } finally {
      setLoading(false);
    }
  };

  return (
    <Card className="w-full max-w-md">
      <CardHeader>
        <CardTitle className="flex items-center gap-2">
          <img src="/mpesa-logo.svg" alt="M-PESA" className="h-6" />
          Lipa na M-PESA
        </CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        <div className="text-2xl font-bold">KES {amount.toLocaleString('en-KE')}</div>

        <div className="space-y-2">
          <label className="text-sm font-medium">M-PESA Phone Number</label>
          <Input
            type="tel"
            placeholder="0712 345 678"
            value={phone}
            onChange={(e) => setPhone(e.target.value)}
            disabled={loading}
            inputMode="tel"
          />
          <p className="text-xs text-gray-500">
            A payment prompt will appear on this phone. Enter your M-PESA PIN to confirm.
          </p>
        </div>

        {status === 'pending' && (
          <div className="text-sm text-amber-700 bg-amber-50 p-3 rounded-lg">
            Check your phone for the M-PESA prompt…
          </div>
        )}
        {status === 'success' && (
          <div className="text-sm text-green-700 bg-green-50 p-3 rounded-lg">
            Payment received. Your order is being processed.
          </div>
        )}
        {status === 'failed' && (
          <div className="text-sm text-red-700 bg-red-50 p-3 rounded-lg">
            Payment failed or timed out. Please try again.
          </div>
        )}

        <Button
          onClick={handlePayment}
          disabled={loading || phone.length < 9}
          className="w-full bg-[#1DA84A] hover:bg-[#168a3c] text-white h-12"
        >
          {loading ? 'Processing…' : 'Pay with M-PESA'}
        </Button>
      </CardContent>
    </Card>
  );
}
```

### 10.4 Middleware: Auth Guard + Role Routing

```typescript
// middleware.ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse, type NextRequest } from 'next/server';

const ROLE_ROUTES: Record<string, string> = {
  patient:    '/dashboard',
  provider:   '/provider/dashboard',
  pharmacist: '/pharmacist/dashboard',
  admin:      '/admin/dashboard',
  rider:      '/rider',
};

export async function middleware(request: NextRequest) {
  const response = NextResponse.next({ request });

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll: () => request.cookies.getAll(),
        setAll: (cookies) => cookies.forEach(({ name, value, options }) =>
          response.cookies.set(name, value, options)),
      },
    }
  );

  const { data: { user } } = await supabase.auth.getUser();
  const path = request.nextUrl.pathname;

  const isPublic = path === '/' || path.startsWith('/login') ||
                   path.startsWith('/register') || path.startsWith('/verify-otp');

  if (!user && !isPublic) {
    return NextResponse.redirect(new URL('/login', request.url));
  }

  if (user && !isPublic) {
    const { data: profile } = await supabase
      .from('profiles')
      .select('role')
      .eq('id', user.id)
      .single();

    const role = profile?.role;
    if (role) {
      const allowedPrefix = ROLE_ROUTES[role];
      const roleRoot = allowedPrefix.split('/')[1];
      const isOnOwnRoute =
        path.startsWith(`/${roleRoot}`) || path === allowedPrefix;

      const isShared = path.startsWith('/profile') || path.startsWith('/settings');
      if (!isOnOwnRoute && !isShared) {
        return NextResponse.redirect(new URL(allowedPrefix, request.url));
      }
    }
  }

  return response;
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|webp)$).*)'],
};
```

### 11.2 M-PESA Service (Flutter)

```dart
// lib/core/services/mpesa_service.dart
import 'package:dio/dio.dart';

class MpesaService {
  final Dio _dio;
  final String _baseUrl;

  MpesaService({required Dio dio, required String baseUrl})
      : _dio = dio,
        _baseUrl = baseUrl;

  Future<MpesaResponse> initiateStkPush({
    required String phone,
    required double amount,
    required String orderId,
    required String orderNumber,
  }) async {
    try {
      final res = await _dio.post(
        '$_baseUrl/api/mpesa/stk-push',
        data: {
          'phone': phone,
          'amount': amount,
          'orderId': orderId,
          'orderNumber': orderNumber,
        },
      );
      return MpesaResponse.fromJson(res.data);
    } on DioException catch (e) {
      throw MpesaException(e.message ?? 'Payment initiation failed');
    }
  }

  /// Polls status until terminal state or timeout.
  Stream<MpesaStatus> pollStatus(String checkoutRequestId) async* {
    final deadline = DateTime.now().add(const Duration(seconds: 90));
    while (DateTime.now().isBefore(deadline)) {
      final res = await _dio.get('$_baseUrl/api/mpesa/status/$checkoutRequestId');
      final status = MpesaStatus.fromJson(res.data);
      yield status;
      if (status.isTerminal) return;
      await Future.delayed(const Duration(seconds: 3));
    }
    yield MpesaStatus.timedOut();
  }
}

class MpesaResponse {
  final String checkoutRequestId;
  final String merchantRequestId;
  final String responseCode;
  final String customerMessage;

  MpesaResponse({
    required this.checkoutRequestId,
    required this.merchantRequestId,
    required this.responseCode,
    required this.customerMessage,
  });

  factory MpesaResponse.fromJson(Map<String, dynamic> json) => MpesaResponse(
        checkoutRequestId: json['CheckoutRequestID'] ?? '',
        merchantRequestId: json['MerchantRequestID'] ?? '',
        responseCode: json['ResponseCode'] ?? '',
        customerMessage: json['CustomerMessage'] ?? '',
      );
}

class MpesaStatus {
  final String status; // pending | succeeded | failed
  final String? receipt;

  MpesaStatus({required this.status, this.receipt});

  bool get isTerminal => status == 'succeeded' || status == 'failed';

  factory MpesaStatus.fromJson(Map<String, dynamic> json) => MpesaStatus(
        status: json['status'] ?? 'pending',
        receipt: json['mpesa_receipt_number'],
      );

  factory MpesaStatus.timedOut() => MpesaStatus(status: 'failed');
}

class MpesaException implements Exception {
  final String message;
  MpesaException(this.message);
  @override
  String toString() => message;
}
```

### 11.3 USSD Fallback Service (Flutter)

```dart
// lib/core/services/ussd_service.dart
import 'package:flutter/services.dart';

class UssdService {
  static const _channel = MethodChannel('com.afyacommerce/ussd');

  /// For feature phones / no-data scenarios.
  /// Dials the M-PESA PayBill USSD string directly.
  static Future<String?> initiateUssdPayment({
    required String amount,
    required String orderNumber,
    required String paybill,
  }) async {
    try {
      final ussd = '*334*1*$paybill*$orderNumber*${amount.toStringAsFixed(0)}#';
      return await _channel.invokeMethod<String>('dialUssd', {'ussdCode': ussd});
    } on PlatformException catch (e) {
      throw Exception('USSD dial failed: ${e.message}');
    }
  }

  /// Opens native SMS composer pre-filled with an order request.
  static Future<void> sendSmsOrder({
    required String pharmacyPhone,
    required String orderDetails,
  }) async {
    await _channel.invokeMethod('sendSms', {
      'phone': pharmacyPhone,
      'body': orderDetails,
    });
  }
}
```

### 11.4 Android USSD Channel (Kotlin)

```kotlin
// apps/mobile/android/app/src/main/kotlin/com/afyacommerce/MainActivity.kt
package com.afyacommerce

import android.content.Intent
import android.net.Uri
import io.flutter.embedding.android.FlutterActivity
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.plugin.common.MethodChannel

class MainActivity : FlutterActivity() {
    private val CHANNEL = "com.afyacommerce/ussd"

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, CHANNEL)
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "dialUssd" -> {
                        val code = call.argument<String>("ussdCode") ?: ""
                        val intent = Intent(Intent.ACTION_CALL, Uri.parse("tel:" +
                            Uri.encode(code)))
                        startActivity(intent)
                        result.success("dialed")
                    }
                    "sendSms" -> {
                        val phone = call.argument<String>("phone") ?: ""
                        val body = call.argument<String>("body") ?: ""
                        val intent = Intent(Intent.ACTION_VIEW, Uri.parse("sms:$phone"))
                        intent.putExtra("sms_body", body)
                        startActivity(intent)
                        result.success("opened")
                    }
                    else -> result.notImplemented()
                }
            }
    }
}
```

## 18. Success Criteria

The build is complete when all of the following are demonstrable:

1. A patient can register with a Kenyan phone number, verify via SMS OTP, and give ODPC consent.
2. A patient can browse the pharmacy catalog, search bilingually (English/Swahili), and filter by county.
3. A patient can upload a prescription; OCR extracts medication names with manual correction.
4. A patient can book a telehealth consultation and complete a video call.
5. A provider can issue a FHIR-compliant e-prescription during or after a consultation.
6. A pharmacist can view the prescription, verify against allergies, and dispense.
7. A patient can check out with M-PESA; STK Push prompt arrives on their phone; payment confirms within 90 seconds.
8. An order triggers boda-boda dispatch; a rider accepts and delivers with photo + OTP proof.
9. The patient can track the rider live on a map.
10. Every PHI access is logged in the immutable audit log with actor, action, timestamp, and IP.
11. All PHI resides on Kenyan infrastructure, verified by network inspection.
12. The platform passes a DPIA and produces a compliant data export on demand.
13. The dashboard loads in under 3 seconds on a simulated 3G connection.
14. USSD fallback successfully dials the M-PESA PayBill string on an Android feature phone.

## 19. Known Limitations & Risks

| Risk | Impact | Mitigation |
|---|---|---|
| **Cloudflare R2 has no African region** | Non-PHI data leaves Kenya | Keep PHI exclusively on Kenyan VPS; document in DPIA |
| **Cloudflare Workers not explicitly HIPAA-listed** | Cannot process PHI in Workers | Treat Workers as network layer only; process PHI in Supabase Edge Functions on Kenyan VPS |
| **Supabase HIPAA add-on unavailable on Free/Pro** | Cloud BAA not possible | Self-host to avoid needing a BAA for PHI storage |
| **Self-hosting Supabase requires DevOps capability** | Operational overhead | Budget for a dedicated DevOps engineer; use automated backup and monitoring |
| **Cloudflare D1 unsuitable for PHI** | 10 GB limit, single-threaded | Use Supabase PostgreSQL for all persistent data |
| **M-PESA callback latency** | Payment status delay up to 90 s | Poll with timeout; show clear "check your phone" UX |
| **No universal Kenyan addressing** | Delivery failures | Landmark field + GPS + phone call fallback |
| **Intermittent rural connectivity** | App unusable offline | Offline-first cache; USSD/SMS fallback |
| **County-level health system fragmentation** | Continuity of care gaps | FHIR-based integration with county HMIS where available |
| **Regulatory timelines (SHA empanelment 30–90 days)** | Delayed launch of claims | Launch without SHA claims; add once empanelled |

## Appendix B: Kenyan Phone Validation Regex

```typescript
// Accepts: +254712345678, 0712345678, 254712345678
export const KENYAN_PHONE_REGEX = /^(?:\+254|254|0)(7\d{8}|1\d{8})$/;

export function normalizeKenyanPhone(input: string): string {
  const digits = input.replace(/\D/g, '');
  if (digits.startsWith('254')) return `+${digits}`;
  if (digits.startsWith('0'))   return `+254${digits.slice(1)}`;
  return `+254${digits}`;
}
```

## Appendix C: KES Currency Formatting

```typescript
export function formatKES(amount: number): string {

}
```
